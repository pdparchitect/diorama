# Downloads and updates

Download `Diorama-arm64.zip` from [GitHub Releases](https://github.com/pdparchitect/diorama/releases), unzip it, and move Diorama to Applications. Requires macOS 15 or later on Apple Silicon.

Release builds are signed and notarized. Use **Diorama → Check for Updates…** to check for a newer version. Settings lets you choose automatic checks and automatic installation separately.

Installing an update restarts Diorama and returns the stage’s windows to a remaining display. Development builds have updates disabled.

See the [changelog](../CHANGELOG.md) for what changed and [security and privacy](security.md) for how updates are verified.
