# Diorama icon

Generated with the built-in image generation tool on 12 September 2026. The existing Diorama icon supplied the desktop-in-a-box concept; Runbar and GoalTracker supplied the sculpted material and lighting references. ModRadio and Puter were also inspected for consistency with the surrounding macOS utilities.

`Support/AppIcon.png` is the final 1254 × 1254 PNG master with real alpha transparency. `make icon` uses native `sips` and `iconutil` to create every standard 1×/2× size in `Support/Diorama.icns`. Both assets are committed; normal builds need no image service.

## Generation prompt

Use case: style-transfer. Asset type: production macOS application icon for Diorama, a virtual desktop inside a window. Input image 1 is the existing Diorama icon to redesign; image 2 Runbar and image 3 GoalTracker are style-only references for the user's family of Mac utility icons. Reimagine the flat first icon as a beautifully sculpted premium 3D macOS icon, matching the material realism and polish of the style references. Subject: a substantial softly rounded brushed dark titanium shadowbox / miniature stage, with a luminous desktop recessed inside; two overlapping small pearl-glass app windows float within the depth, each with three tiny colored window-control dots, no writing. Subtle blue-violet desktop light inside the box, clean metallic bevels catching soft studio highlights, realistic ambient occlusion and carefully controlled reflections. The stage reads as a desktop in a box at small Dock sizes. A midnight navy rounded-square backing tile integrates with the sculpture; centered, nearly frontal with very slight top and side depth, generous simple silhouette, square composition, entire icon and soft edge shadow visible with about 5 percent transparent padding on all sides. True transparent background outside the rounded-square icon, preserve alpha. No monitor stand, no keyboard, no extra objects, no letters, no text, no watermark, no flat vector art, no excessive neon bloom. Produce one finished square icon, at least 1024 by 1024.

## Transparency refinement

The first result included a drawn checkerboard. A second built-in edit removed it while preserving the icon. Prompt: “Background extraction edit only. Preserve this Diorama app icon EXACTLY, including all materials, geometry, windows, colors and lighting. REMOVE the gray checkerboard outside the rounded-square icon completely. The area outside the rounded square MUST be actual transparency, an alpha channel with zero opacity. No drawn checkerboard, no solid backdrop. Preserve the antialiased rounded-square edge. Output one production PNG icon with real transparent pixels.” The final PNG’s alpha channel was verified before packaging.
